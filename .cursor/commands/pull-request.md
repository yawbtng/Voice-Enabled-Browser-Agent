# Create PR

## Overview
Create a well-structured pull request with proper description, labels, and reviewers.

## Steps
1. **Prepare branch**
   - Ensure all changes are committed
   - Push branch to remote
   - Verify branch is up to date with main

2. **Write PR description**
   - Summarize changes clearly
   - Include context and motivation
   - List any breaking changes
   - Add screenshots if UI changes

3. **Set up PR**
   - Create PR with descriptive title
   - Add appropriate labels
   - Assign reviewers
   - Link related issues

## Pull Request Checklist

**Changes Included**
- [ ] New feature implemented (describe below)
- [ ] Bug fix or patch applied (describe below)
- [ ] Documentation updated as needed
- [ ] Refactoring or code cleanup carried out

**Testing**
- [ ] Unit tests added or updated as appropriate
- [ ] All unit tests pass locally
- [ ] Manual testing completed for all major changes
- [ ] No new warnings or errors introduced

**Developer Actions**
- [ ] Code reviewed for clarity and maintainability
- [ ] Related issues linked in the description
- [ ] PR description summarizes context and motivation

**Additional Details**
_Optional: Please provide any extra context, screenshots, or links to documentation relevant to the changes._
